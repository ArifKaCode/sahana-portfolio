CricPose — Cricket Shot Analysis & Pose Evaluation System

Project Overview

CricPose is a computer vision and machine learning-based system designed to analyze cricket batting shots, evaluate player posture, and provide joint-angle correction suggestions.

Problem Statement

Evaluating batting biomechanics and posture manually from match footage is subjective and time-consuming. CricPose automates batter silhouette isolation, classifies shots across four categories, and computes joint-angle posture feedback.

Methodology & Implementation

  • Engineered an automated image segmentation pipeline using Python and OpenCV to isolate batter silhouettes from cricket match frames.
  • Developed and validated a supervised machine learning classification model using scikit-learn to identify four different cricket shots.
  • Created a programmatic test-image generator with verified ground-truth labels to benchmark model performance.
  • Built an interactive Flask web application that scores batting posture and recommends targeted joint-angle corrections.

Verified Results & Performance

  • 96.2% test accuracy in cricket shot classification across 4 shot categories.
  • 0.96 Intersection over Union (IoU) score on test images for batter segmentation.

Technologies Used

Python, OpenCV, scikit-learn, Flask
